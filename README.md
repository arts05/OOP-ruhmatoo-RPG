# OOP-ruhmatoo-RPG
Repositoorium LTAT.03.003 rühmatöö jaoks (konsoolipõhine rollimäng).
Loojad on Rene ja Arthur.

# Teema
Tegemist on *turn-based* rollimänguga, kus mängija peab võitlema suure lohega. Eesmärk on lohet võita ning printsess päästa. Võitlemissüsteem hõlmab kaitset ja rünnet, hoiakuid ja relvatüüpe (vibu või mõõk). Mäng käib läbi konsooli ehk ilma graafilise liideseta.
